What the editor does

Every control updates the preview as you move it. Settings are shared across every file you open, so a batch looks consistent.

Dithering

Bayer 2–16, clustered dot, blue noise and your own matrices; Floyd–Steinberg, Atkinson, Sierra, Burkes, Jarvis and Stucki diffusion.

Palettes

Built-ins from Lospec, palettes pulled from the image, colours picked by hand, and .gpl, .hex, .pal or Lospec imports.

Batches

Drop a folder's worth of images, tune once, and download them all as one ZIP with the settings file inside.

Video

Preview while it plays, step frame by frame, then export GIF, WebM, MP4 or a PNG sequence. Every frame is processed exactly once.

Game-ready output

Integer-scaled PNGs, indexed PNGs, sprite sheets with a JSON atlas, and deduplicated tilesets with a tile map.

Share a look

Copy a link that carries your settings, or save them as JSON. Undo and redo cover every change.

Use the engine in your own code

The editor is built on a small library with no UI. Import it as an ES module or drop in a script tag; TypeScript types are included.

Library reference

How it renders

Each step is a WebGL fragment shader run through ShaderMate. Error diffusion is normally one pixel at a time; here it runs as a diagonal wavefront, so every pixel on a wave is solved in parallel and the result still matches the sequential algorithm.

How it works

  • Prepare. Box-filter resample, brightness, contrast, saturation, gamma, alpha cut.
  • Quantise. Nearest palette colour in OKLab, with an ordered threshold or a diffusion wave.
  • Clean up. Stray-pixel removal, majority smoothing, inner or outer outline.
  • Export. Read back once; PNG, GIF, ZIP and video encoders run in the page.
