# Keyboard shortcuts

On macOS use <kbd>⌘</kbd> for <kbd>Ctrl</kbd>.

| Action | Keys |
| --- | --- |
| Open files | <kbd>Ctrl</kbd> <kbd>O</kbd> |
| Paste image or palette | <kbd>Ctrl</kbd> <kbd>V</kbd> |
| Export PNG | <kbd>Ctrl</kbd> <kbd>S</kbd> |
| Undo | <kbd>Ctrl</kbd> <kbd>Z</kbd> |
| Redo | <kbd>Ctrl</kbd> <kbd>Shift</kbd> <kbd>Z</kbd> or <kbd>Ctrl</kbd> <kbd>Y</kbd> |
| Compare with original | <kbd>C</kbd> |
| Pixel grid | <kbd>G</kbd> |
| Fit to view | <kbd>F</kbd> |
| Zoom in / out | <kbd>+</kbd> <kbd>-</kbd> |
| Pixel width −1 / +1 | <kbd>[</kbd> <kbd>]</kbd> |
| Pixel width −8 / +8 | <kbd>Shift</kbd> <kbd>[</kbd> <kbd>]</kbd> |
| Next / previous dither method | <kbd>D</kbd> / <kbd>Shift</kbd> <kbd>D</kbd> |
| Play / pause video | <kbd>Space</kbd> |
| Previous / next frame | <kbd>,</kbd> <kbd>.</kbd> |
| Next / previous file | <kbd>Alt</kbd> <kbd>↓</kbd> / <kbd>Alt</kbd> <kbd>↑</kbd> |
| Move the current file down / up | <kbd>Alt</kbd> <kbd>Shift</kbd> <kbd>↓</kbd> / <kbd>↑</kbd> |
| File menu (on a focused file row) | <kbd>Shift</kbd> <kbd>F10</kbd> or the menu key |
| Toggle library | <kbd>\</kbd> |
| Toggle inspector | <kbd>/</kbd> |
| Dark / light theme | <kbd>T</kbd> |
| Shortcut list | <kbd>?</kbd> |
| Stop picking colours, close menus | <kbd>Esc</kbd> |

Single-key shortcuts are ignored while you type in a text or number field. Everything is also reachable with <kbd>Tab</kbd>; focused controls show a ring.
